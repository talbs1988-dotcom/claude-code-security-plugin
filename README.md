# אבטחת סביבת Claude Code

## הבעיה

Claude Code עובד כ-agent — יש לו גישה לקבצים שלך, לטרמינל, ולאינטרנט.

בתוך הפרויקטים שלך יש קבצי `.env` עם כל המפתחות: Stripe, OpenAI, WhatsApp, חשבון ה-AWS שלך. אם Claude מקבל בקשה לקרוא את הקובץ הזה — בין אם ממך ובין אם מקובץ זדוני שנכנס לפרויקט — הוא יקרא אותו. כי ברירת המחדל היא: מותר הכל.

זה לא כשל של Claude. זו ברירת מחדל שמניחה שאתה סומך על הכל. ואתה לא צריך לסמוך על הכל.

## הפתרון — 3 שכבות

**שכבה 1: שלט "אין כניסה"**
קובץ `settings.json` מקבל כלל שחוסם קריאת `.env` — Claude לא יוכל לגשת לקובץ הזה גם אם יבקשו ממנו. זה לא שאלה של כוונה, זה חסימה ברמת ההרשאות.

**שכבה 2: השומר בפתח**
כל פקודה שClaude מנסה להריץ עוברת בדיקה אוטומטית לפני ביצוע. ניסיון לקרוא `.env` דרך הטרמינל — נחסם עם הודעה ברורה, לפני שהפקודה מגיעה למעטפת.

**שכבה 3: כללי בית**
Claude קורא קובץ `CLAUDE.md` בתחילת כל שיחה. אנחנו כותבים שם את הכללים: אל תרשום API keys בקוד, אל תקרא קבצי סודות, לפני שרת MCP חדש — בקש אישור.

שלוש שכבות. אף אחת מהן לא מספיקה לבד. ביחד הן יוצרות הגנה שמקשה מאוד על כל ניסיון — מכוון או בטעות — לחשוף את הסודות שלך.

## התקנה — הודעה אחת לצ'אט

פתחי Claude Code, הדביקי את ההודעה הזו ושלחי:

```
קרא וקיים: https://raw.githubusercontent.com/talbs1988-dotcom/claude-code-security-plugin/main/plugins/security-hardening/skills/security-and-hardening/SKILL.md
```

Claude יעשה את הכל: יבצע את 3 השכבות ויאשר שהכול ירוק. **לא צריך restart.**

---

## מה Claude יעשה

1. **יבדוק** אם `jq` מותקן (נחוץ לhook) — אם לא, ינחה אותך להתקין
2. **יוסיף deny rules** ל-`~/.claude/settings.json` — חוסמות קריאת `.env`
3. **יוסיף security hook** שמונע `cat .env` מהטרמינל
4. **יוסיף כללי אבטחה** ל-`~/.claude/CLAUDE.md`
5. **יריץ בדיקת תקינות** ויאשר ✅ לכל שכבה
